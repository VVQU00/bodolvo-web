PDF Toolkit Pass 10: merge, split to ZIP, extract/remove/rotate/reorder, image-to-PDF, PDF-to-images ZIP, preview, lossless optimization and optional flattening.
Required dependencies: npm install pdfjs-dist@^5 jszip@^3.
Run npm run build before committing. Password protection, unlocking, OCR, and signing are not implemented. Preview PDF browser support varies.
