# Bodolvo Tools — Pass 07: Magnifier

Full project ZIP building on Pass 06.

Magnifier: open or switch a camera; freeze a frame; upload a local photo; zoom up to 8×; drag a frozen image to pan; adjust brightness and contrast; save a magnified PNG; use flashlight where supported. All image handling is in-browser.

Extract into your existing project, run `npm run dev`, and visit `/apps/magnifier`. Camera requires permission and HTTPS (or localhost). Some browsers do not support camera selection or flashlight.

Other existing routes remain included. No credential files are included.
